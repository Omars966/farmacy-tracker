# AI CV Vērtētājs

Projekts, kas izmanto Google Gemini Flash 2.5, lai novērtētu kandidātu CV atbilstību darba aprakstam.

## Struktūra
- `app.py` — galvenais skripts
- `config.py` — API atslēga un iestatījumi
- `inputs_files/` — ievades faili (JD un CV)
- `output_files/` — izvades faili (JSON ar vērtējumiem)
- `prompts.md` — Gemini prompta teksts
- `README.md` — projekta apraksts
